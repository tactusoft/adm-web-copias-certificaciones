Términos y Condiciones

La SUPERINTENDENCIA DE INDUSTRIA Y COMERCIO, es responsable del tratamiento de los datos personales obtenidos a través de este sistema de copias y certificaciones. Los datos aquí gestionados se utilizan para la finalidades etablecidas y en últimas para las finalidades dispuestas en la Política de Tratamiento de Datos personales, literal 8.1. página 11.

Como titular de los datos personales, podré ejercer mis derechos a conocer, actualizar, rectificar y suprimir mi información personal cuando ello fuera posible, así como el derecho a revocar el consentimiento otorgado para el tratamiento de sus datos personales. El canal dispuesto por la SUPERINTENDENCIA DE INDUSTRIA Y COMERCIO para la atención de sus solicitudes las puede llevar a cabo a través de este enlace.

La Política de Tratamiento de Datos Personales, se encuentra publicada en este enlace.
